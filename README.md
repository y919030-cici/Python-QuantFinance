# Python Quant Finance

A personal project documenting my journey in Python programming and quantitative finance.

## Project 01 — Stock Return Analysis

### Objective
Calculate daily and cumulative stock returns using Python and pandas.

### Methods
- Daily returns using `pct_change()`
- Cumulative returns using `cumprod()`
- Numerical validation

### Key Finding
Simple returns must be compounded rather than directly added to calculate cumulative investment returns.

### Data
Synthetic stock closing prices for reproducible practice.

### Files
- `stock_returns.py`: Python implementation.
- `stock_returns.csv`: Generated dataset.
